DESCRIPTION
This is a console-based chat application developed in Java that allows multiple clients to connect to a server and communicate with each other in real-time. The project demonstrates the use of Java Sockets, multithreading, and I/O streams for building a basic client-server network application.

Features

Multiple clients can connect to the server simultaneously.

Real-time message broadcasting to all connected clients.

Clients can send and receive messages independently.

Clean exit using the exit command.

Console-based, lightweight, and easy to extend.

Technologies Used

Java (core)

Socket Programming (TCP)

Multithreading (Runnable and Thread)

I/O Streams (BufferedReader, PrintWriter)

How to Run

Clone the repository:

git clone <your-repo-url>


Run the Server:

Open ChatServer.java → Run the main method.

Server starts listening on port 12345.

Run Clients:

Open ChatClient.java → Run the main method.

Multiple clients can run simultaneously.

Chat:

Type messages in the client console.

Type exit to disconnect.

Sample Output

Server Console:

Received: Hello everyone!


Client Console:

Welcome to the chat! Type 'exit' to leave.
